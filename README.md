# Nihonki

### AI powered translation tool for android

Nihonki is a work in progress application that is designed to quickly create Japanese flashcards for the AnkiDroid Spaced Repetition Flashcard app formatted in the Core 2k style available [here](https://ankiweb.net/shared/info/2141233552). While not currently available it is approaching the end of my personal testing and will be released soon on google play!
